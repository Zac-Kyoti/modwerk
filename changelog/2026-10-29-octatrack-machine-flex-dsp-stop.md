Octatrack base (beta): a track that leaves Analog BD (or another module machine with its own sound) for FLEX at a bank, pattern or Part change while the sequencer plays no longer stops the DSP. Each trig on the machine also started stock's hidden FLEX voice from the machine's settings, and when the track became FLEX again stock played that voice; on a track that had been the machine since power-on, its first FLEX frame stopped the DSP until a power cycle (#1051's family). The base now keeps that voice stopped while the machine renders the track, so the track is silent until its first FLEX trig. Checked in the host test and on an MKII (see the pull request).
